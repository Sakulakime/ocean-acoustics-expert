# Book PDFs

This folder holds the book PDFs the expert reads page ranges of when the notes do not settle a question. The package ships no books: put your own copies here, under these exact file names (ADR 0006).

| File name | Book |
|---|---|
| `jensen-2011-computational-ocean-acoustics.pdf` | Jensen, Kuperman, Porter & Schmidt, *Computational Ocean Acoustics*, 2nd ed. (2011) |
| `collins-siegmann-2019-parabolic-wave-equations.pdf` | Collins & Siegmann, *Parabolic Wave Equations with Applications* (2019) |
| `colosi-2016-sound-propagation-stochastic-ocean.pdf` | Colosi, *Sound Propagation through the Stochastic Ocean* (2016) |
| `etter-2018-underwater-acoustic-modeling-simulation.pdf` | Etter, *Underwater Acoustic Modeling and Simulation*, 5th ed. (2018) |
| `brekhovskikh-lysanov-2003-fundamentals-ocean-acoustics.pdf` | Brekhovskikh & Lysanov, *Fundamentals of Ocean Acoustics*, 3rd ed. (2003) |

Page numbers in the notes are PDF pages of these editions. Git ignores PDFs in this folder.
