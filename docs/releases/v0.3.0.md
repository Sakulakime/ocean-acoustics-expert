# v0.3.0 — UMPE support

- **Added:** A UMPE solver guide, input templates and a checklist. The installer detects your UMPE source tree or accepts `--umpe-root`. `validate_umpe_inp` checks the column-33 colon, decimal points, count limits and sediment thickness without running the solver.
- **Fixed:** The [optional UMPE v1.1 metric range-index patch](https://github.com/Sakulakime/ocean-acoustics-expert/blob/v0.3.0/knowledge/runbooks/umpe-runbook.md#preserve-the-official-ex4b-input-mks-range-index-fix) lets the original `ex4b` input run without an extra output record: 1,000 ranges × 171 depths. All eight official examples passed with bounds checking. Installation does not modify your solver.
- **Requirements:** Node.js 22+ and npm/npx for installation and input checks. To build UMPE on Linux, supply its source, `gfortran` and `make`; add `patch` for the fix. Python 3.10+ is only needed to replay the example suite from a repository checkout. No MATLAB is needed for UMPE.

Install or update: `npx --yes ocean-acoustics-expert@0.3.0 install`.
